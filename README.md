# story painter

## pry 改版：紫藤星环界面

站点标题为「跑团log染色器-pry改版」。界面参考 [TRPG-LogColorizer](https://github.com/DiceZone/TRPG-LogColorizer) 的侧栏设置与主区域编辑/预览布局，在本分支原有代码上实现紫色、宇宙星环与紫藤花主题，支持浅色和深色模式。手机上编辑区优先显示，设置面板排在其后。

左侧集中角色配色、头像、过滤排版与导出；右侧提供文本编辑、列表编辑、阅读预览、头像与差分、论坛代码和回声工坊六种视图。保留 CCF 导入、列表分组与合并、拖拽排序、差分工作台、自定义背景，以及原始日志、Word、对话 Word、HTML 单文件和 HTML ZIP 导出。统一导入按钮支持 TXT、LOG、JSON、CCF / SealChat HTML 和 SealChat HTML ZIP 日志包。

沿用原有远程接口、浏览器存储键与导出引擎。进入工作台时编辑器保持挂载；从列表切换视图或导出之前，会先同步待处理的修改。

「选择文件导入日志」用于替换当前日志，旁边注明支持的格式；「追加多个文件」直接打开列表编辑中的追加导入面板。角色卡可编辑名字和 ID，点击保存后同步到日志、预览和导出；同名同 ID 的角色合并，并保留目标角色的配色、身份和头像。不同名字即使 ID 相同也保持独立。角色列表限制高度并独立滚动，超过 5 个角色时提供名字/ID 搜索及角色、过滤排版、导出的悬浮快捷跳转。

修复编辑格式转换时重复追加换行的问题：导入和刷新统一使用一个空行分隔发言，正文内部段落空行保持原样；连续文本编辑保留正在输入的空白与正确索引，不再在多次转换后累积空行。

角色列表默认可完整显示约 4 位角色，可点击「展开更多角色」增加至约 8 位，再次点击收起；更多角色仍可搜索或在列表内滚动。桌面编辑/预览区保留已经展开的高度，折叠左侧卡片、收起角色列表或搜索角色时不会跟着缩短；手机端沿用独立的编辑区高度。

### 头像、差分与 HTML 样式

工作台提供基础排版、HTML 样式、头像与差分三个面板，以及实际日志的实时导出预览。可调整字号、行距、内容宽度、消息间距和头像尺寸/圆角，导入或编辑 HTML、CSS、设计变量和模板匹配规则，下载样式 ZIP 备份。支持 SealChat v1 样式包的消息模板、片段、规则及图片/字体资源。

SealChat 标准 JSON、HTML 分片及完整 HTML 日志 ZIP 可以导入或追加。HTML 按每条发言的头像恢复差分；同名不同 ID 的角色分别管理，支持差分缩略图、多图上传和使用次数显示。标准 JSON 不包含头像差分，HTML 也未保存原差分名称/编号，因此生成稳定的 `sc-…` 标签；引用旧差分编号的样式规则需要调整。兼容格式、模板写法及保存范围见 [SealChat 兼容说明](docs/sealchat-compatibility.md)，工作台内也有可点击的「使用说明」。

### 多窗与内容块编排

列表编辑提供「顺序列表」「内容块编排」与「窗口对照」，右侧仅保留窗口统计。窗口对应 main、HO1、HO2 等频道；内容块是用户手动选择、一起移动的一段发言，不要求每条发言都分块。工具栏的「使用说明」可随时打开，包含操作步骤、穿插示例、快捷键和保存范围。

- 追加多个 TXT / LOG / JSON / HTML / SealChat ZIP 文件，每个文件可设置导入窗口，也可先进入待分拣；卡片分别标记来源文件和当前窗口，跨窗移动后来源不变。
- 拖动发言或整块只改变阅读顺序，保留窗口、来源和时间。需要修改窗口归属时，在窗口对照中勾选并「确认改窗」。支持窗口重命名与合并、单窗 TXT 导出；移除窗口会将发言放回待分拣。
- 聚焦整理工作区时，数字键 1–9 将首条可见待分拣记录送入对应窗口。输入框内不触发分拣快捷键；也可使用移动按钮。
- 勾选发言后「组成内容块」，选中不连续内容时会按当前顺序聚拢到最早选中位置。块名可选，同名或同窗口的块不会自动合并。块头支持拖动、上下移动、重命名、展开编辑、解除分块；勾选两个以上块才可「合并选中块」。
- 「移出内容块」保留发言所在位置；若从块中间移出，前后部分成为独立块。解除分块不删除正文。正文空行可拆成独立发言；连续且同角色、窗口、旧场景、差分和内容块归属的发言可合并正文。
- 保留最近 20 步撤销 / 重做，涵盖建块、拆块、合并和移动，支持 Ctrl / ⌘ Z 和 Ctrl / ⌘ Shift Z。搜索正文、角色、账号、窗口、块名、旧场景和来源，支持上下一个结果；定位时自动展开块，并滚动到对应发言。
- 内容块视图按最终导出顺序排列。窗口或来源筛选会显示包含匹配发言的完整块，移动时包含块内全部发言。已有内容块时，追加文件接在末尾，不重新按时间打散编排。
- 窗口与原有场景标签兼容已有日志的 `[main › 场景名]` 格式；内容块名称不写入导出正文。分块、来源文件标记和撤销历史仅保留在当前页面会话；切换预览不会清除，刷新页面不会恢复。在文本模式直接修改内容后，整理历史会重置，仍连续的块尽量保留；导入整份新日志会清空分块。

修复了刷新文本时丢失组名，以及含频道日志遇到正文空行时截断段落的问题。补充整理状态与核心解析链路的回归测试。

交互思路参考 [Freecell-log-studio](https://github.com/FreecellRaid/Freecell-log-studio) 的场景整理、历史操作与搜索定位，以及 [trpg-log-sorter](https://github.com/lcmdyc/trpg-log-sorter) 的多窗分拣与待处理队列。实现基于本项目的数据和导出流程，未复制参考项目源码。参考说明仅保留在仓库中。

### 外观定制

- `src/styles/wisteria.scss`：以紫藤花瓣的紫色为主，浅色采用淡紫和暖白面板，深色采用紫灰面板，叶片绿用于少量点缀。桌面主编辑/预览面板与侧栏导出区底部对齐；编辑器为原版 18px，阅读预览为 16px。
- `src/App.vue`：Naive UI 控件配色，与页面主题一致。
- `src/components/OrbitMark.vue`：本地 SVG 星环装饰。
- `src/components/WisteriaDecoration.vue`、`public/wisteria-art-illustration-clipart.png`：用户提供的透明 PNG 原图，本地加载；仅通过 CSS 缩放与布局裁切，图片透明度和原始文件保持不变。素材来源记录在组件注释中，不显示在网页上。
- `src/Main.vue`、`index.html`：页面文案与浏览器标题。
- `src/sample.ts`：首次打开时使用海豹 Story Painter 原版默认示例，完整保留海豹一号机、木落和芝士雪豹的日志内容。

开发与检查沿用 `pnpm install --frozen-lockfile`、`pnpm dev`、`pnpm test`、`pnpm build`。构建产物仍为 `dist`，沿用原部署方式。
